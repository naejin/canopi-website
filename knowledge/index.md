# Subdirectories

* [conventions](conventions/index.md) - A rule the codebase follows (style, patterns, do/don't).
* [decisions](decisions/index.md) - An ADR: a decision, its context, and its consequences.
* [modules](modules/index.md) - A code module/package/service: responsibility and interfaces.
* [project](project/index.md) - What the project is, who it serves, and how it is laid out.
* [references](references/index.md) - A pointer to existing documentation or external material.
* [runbooks](runbooks/index.md) - Step-by-step operational procedure: build, test, release, debug.
